# Классификация новостей РБК по рубрикам

Многоклассовая классификация русскоязычных новостных статей — от сбора данных
собственным парсером до сравнения четырёх нейросетевых архитектур.

## Данные

**8142 статьи** с rbc.ru за апрель–май 2024, собранные парсером
(`Парсер_RBC.ipynb`). Семь рубрик: Политика, Общество, Спорт, Бизнес,
Экономика, Технологии и медиа, Финансы.

Выгрузки лежат в `data/` тремя файлами по периодам сбора.

## Подход

TF-IDF-векторизация текстов, отложенная выборка 15%, ранняя остановка и
сохранение лучшей контрольной точки по `val_loss`.

## Результаты

| Модель | Средняя точность распознавания | Лучшая `val_accuracy` |
|---|---:|---:|
| **Simple BoW** (полносвязная) | **79%** | 0.883 |
| Conv1D BoW | 76% | 0.880 |
| Embedding + Conv1D | 76% | 0.865 |
| RNN BoW | 70% | 0.829 |

Лучшая модель дополнительно проверена на сторонней новостной статье, не
входившей в выборку.

## Вывод

**Победила самая простая архитектура.** Обычная полносвязная сеть на мешке
слов обошла и свёрточные модели, и рекуррентную.

Объяснение в природе задачи: на корпусе такого размера рубрика новости
определяется прежде всего **словарём**, а не порядком слов. «Матч», «сборная»,
«тренер» относят текст к спорту независимо от того, в каком порядке они стоят.
Рекуррентная сеть — единственная из четырёх, кто моделирует порядок, — и
оказалась худшей: она тратит ёмкость на структуру, которая для этой задачи
почти не несёт сигнала.

Во всех моделях заметно переобучение: точность на обучающей выборке доходит до
0.99, тогда как валидационная держится около 0.86. Отсюда ранняя остановка по
`val_loss` и сохранение лучшей контрольной точки, а не последней.
